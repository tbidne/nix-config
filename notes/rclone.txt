#                                     Misc                                    #
###############################################################################

- https://rcloneui.com/docs/cli/faq/why-is-it-slow

- Extracting archives via the web interface does not work for me. It is _much_ faster
  to upload archives than individual files, though, so instead of 'rclone copy' we
  should 'rclone mount', then copy the directory and extract (seems to work).

- Empty files cannot be deleted directly from pcloud, so make sure test files are
  non-empty.

- In general, make sure uploaded files are squared away with permissions,
  owner/group non-root.

- rclone perf tips: https://rcloneui.com/docs/cli/faq/why-is-it-slow
